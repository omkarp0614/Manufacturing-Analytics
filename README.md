Manufacturing Analytics

A data analysis project on manufacturing sales & inventory data — covering data cleaning, SQL-based analysis, and interactive dashboards built in both Tableau and Power BI.

📌 Project Overview

This project analyzes manufacturing sales and inventory data to identify trends, patterns, and opportunities for better inventory planning and sales performance. It combines SQL for data extraction/cleaning, and interactive dashboards built in Excel, Power BI, and Tableau for visualization and reporting.

Objective: "Analyze sales trends and inventory levels across products/regions to identify slow-moving stock and demand patterns, and present findings through interactive dashboards."

🛠️ Tools & Technologies
SQL — data extraction, cleaning, and querying
Excel — data analysis, pivot tables, and dashboard
Power BI — interactive dashboard & DAX measures
Tableau — interactive dashboard & visual analytics
📊 Key Areas Analyzed
Sales trends (by product / region / time period)
Inventory levels vs. demand
Stock turnover / slow-moving items

🗂️ Repository Structure

├── tableau/             # Tableau (.twbx) dashboard file

🚀 How to Use
Clone this repository
Run the SQL scripts in sql/ against the dataset to reproduce the cleaned tables
Open the Excel file in excel/ to explore the dashboard, pivot tables, and charts
Open the .pbix file in Power BI Desktop, or the .twbx file in Tableau, to explore the interactive dashboards
